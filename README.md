# More Comfortable cloth / 女角色更舒适的服装立绘替换

This mod replaces the character portraits for several female characters in *Hades II*, giving them more comfortable, practical pants and outfits. The goal is to make the attire more suitable for combat and allow players to focus better on the characters' facial expressions and the story.

这个 Mod 替换了《Hades II》中几位女性角色的立绘，为她们换上了更舒适、更实用的裤装。这样调整不仅让服装更符合战斗逻辑，也希望能让大家的视线更好地回归到人物丰富的面部表情和精彩的剧情本身上。

## Modified Characters / 替换角色列表

**Standard Portraits / 常规立绘:**
*   **Melinoe** (墨利诺厄)
*   **Hera** (赫拉)
*   **Nemesis** (涅墨西斯)
*   **Artemis** (阿尔特弥斯)
*   **Eris** (厄里斯)
*   **Medea** (美狄亚)

**Bath Portraits / 温泉立绘:**
*   **Melinoe** (墨利诺厄)
*   **Nemesis** (涅墨西斯)
*   **Eris** (厄里斯)

## Important Notes / 注意事项 (Please Read / 必读)

1.  **Melinoe's Blinking Issue / 墨利诺厄的眨眼错位问题**:
    Due to the adjustment of Melinoe's overall height in the portrait, there is a misalignment with her blinking animation. This is a known technical limitation and cannot be fixed at the moment.  
    由于对墨利诺厄的立绘高度进行了调整，导致她的眨眼动画出现了错位。这是一个目前无法修复的技术限制，请见谅。

2.  **Facial Adjustments / 面部微调**:
    Some characters have slight facial adjustments based on the artist's personal preference.   
    部分角色的面部基于个人倾向进行了微调。

##  Installation / 安装方法

*   **Recommended (Recommended for automatic dependencies) / 推荐方法:**
    Subscribe to this mod using **r2modman** or **Thunderstore Mod Manager**. All required dependencies (Hell2Modding, ModUtil, etc.) will be installed automatically.  
    推荐使用 **r2modman** 直接下载安装，所有前置依赖（Hell2Modding、ModUtil 等）都会自动为你配齐。

*   **Manual Installation / 手动安装**:
    If you install manually, please ensure that your `Hades II\Ship\ReturnOfModding\plugins` folder contains **ALL** of the following support files and dependencies:  
    如果你选择手动安装，请确保 `Hades II\Ship\ReturnOfModding\plugins` 文件夹中有以下全部的文件（一部分是 mod 需要的支撑，一部分是支撑需要的底层依赖）：  
    - `Hell2Modding-GLOBAL`
    - `LuaENVY-ENVY`
    - `SGG_Modding-Chalk`
    - `SGG_Modding-DemonDaemon`
    - `SGG_Modding-ENVY`
    - `SGG_Modding-ModUtil`
    - `SGG_Modding-ReLoad`
    - `SGG_Modding-SJSON`
    Download this mod and extract it into your `Hades II\Ship\ReturnOfModding\plugins` folder.  
    下载本 Mod 解压至游戏目录下的 Ship\ReturnOfModding\plugins 文件夹中。
